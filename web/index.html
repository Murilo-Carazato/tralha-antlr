Gramática Aumentada com 11 regras. A estrutura em camadas (expr → termo → fator) implementa nativamente a precedência de operadores e associatividade à esquerda.
0. S' → S // Regra aumentada para parada segura
1. S → lista
2. lista → lista comando // Recursão à esquerda: múltiplos comandos
3. lista → comando
4. comando → ID receba expr ; // Atribuição de valor
5. expr → expr + termo // Adição (associativa à esquerda)
6. expr → termo
7. termo → termo * fator // Multiplicação (maior precedência)
8. termo → fator
9. fator → ( expr ) // Parênteses: isolamento de subexpressão
10. fator → NUM // Constante numérica
11. fator → ID // Variável / Identificador
