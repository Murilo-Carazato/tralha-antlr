No analisador SLR(1), os conjuntos FOLLOW determinam rigorosamente em quais colunas de terminais as ações de redução (rN) são inseridas.
Não-Terminal: S Símbolo Inicial
  • FIRST(S): { ID }
  • FOLLOW(S): { $ }
  • Reduz para S apenas quando encontra o fim da entrada ($).
Não-Terminal: lista Sequência
  • FIRST(lista): { ID }
  • FOLLOW(lista): { ID, $ }
  • Permite encadear outro comando (ID) ou finalizar ($).
Não-Terminal: comando Atribuição
  • FIRST(comando): { ID }
  • FOLLOW(comando): { ID, $ }
  • Inicia sempre com o identificador da variável (ID).
Não-Terminal: expr Adição
  • FIRST(expr): { (, NUM, ID }
  • FOLLOW(expr): { ;, +, ) }
  • Reduções r5 e r6 inseridas apenas em ;, +, ).
Não-Terminal: termo Multiplicação
  • FIRST(termo): { (, NUM, ID }
  • FOLLOW(termo): { ;, +, *, ) }
  • Reduções r7 e r8 inseridas em ;, +, *, ).
Não-Terminal: fator Base / Operando
  • FIRST(fator): { (, NUM, ID }
  • FOLLOW(fator): { ;, +, *, ) }
  • Reduções r9, r10 e r11 inseridas em ;, +, *, ).

Gramática Aumentada com 11 regras. A estrutura em camadas (expr → termo → fator) implementa nativamente a precedência de operadores e associatividade à esquerda.
0. S' → S // Regra aumentada para parada segura
1. S → lista
2. lista → lista comando // Recursão à esquerda: múltiplos comandos
3. lista → comando
4. comando → ID receba expr ; // Atribuição de valor
5. expr → expr + termo // Adição (associativa à esquerda)
6. expr → termo
7. termo → termo * fator // Multiplicação (maior precedência)
8. termo → fator
9. fator → ( expr ) // Parênteses: isolamento de subexpressão
10. fator → NUM // Constante numérica
11. fator → ID // Variável / Identificador
